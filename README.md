# LegalEase

LegalEase is an AI-powered legal document assistant focused on English and Marathi documents.

## Features

- PDF document extraction
- Scanned PDF OCR
- DOCX text extraction
- JPG/JPEG/PNG OCR
- English ↔ Marathi document translation
- Document summarization
- Key information extraction
- Legal language simplification
- Structured legal document analysis

## Supported Documents

- PDF
- DOCX
- JPG
- JPEG
- PNG

## Translation

LegalEase uses fine-tuned IndicTrans2 models for English ↔ Marathi translation.

## Technology

- Python
- FastAPI
- HTML/CSS/JavaScript
- Tesseract OCR
- PyMuPDF
- python-docx
- IndicTrans2
- PyTorch

## Disclaimer

LegalEase is an educational project intended to help users understand legal documents. Its output should not be treated as legal advice.
